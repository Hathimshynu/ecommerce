## 🎓 How to Use

### Step 1: Start Development
```bash
cd d:\Projects\ecommerce
php artisan serve
npm run dev
```

### Step 2: Visit in Browser
```
http://localhost:8000
```

### Step 3: Test Features
1. Click menu items to filter
2. Click + on product to add to cart
3. Click cart icon to view items
4. Click checkout to complete purchase

### Step 4: Explore Admin
```
http://localhost:8000/admin
# (requires authentication setup)
```
